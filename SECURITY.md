# Sicherheitsrichtlinie für burroQueue

## Unterstützte Versionen

| Version | Unterstützt |
|---|---|
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Sicherheitslücken melden

Wenn du eine Sicherheitslücke in `burroQueue` entdeckst:

1. Öffne bitte **kein** öffentliches Issue im GitHub-Repository.
2. Melde die Schwachstelle vertraulich per GitHub Security Advisory oder per E-Mail an den Repository-Maintainer.
3. Bitte beschreibe:
   - Art der Schwachstelle (z. B. Denial-of-Service via UDP-Multicast, Command Injection via URL Drop)
   - Schritte zur Reproduktion (Proof-of-Concept)
   - Mögliche Auswirkungen auf das lokale Büronetzwerk

Wir prüfen jede Meldung unverzüglich und stellen schnellstmöglich einen Patch bereit.
